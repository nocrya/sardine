# Sardine 教学版学习手册

这套文档是在 `docs/learning-path` 的基础上再往前走一步。

如果说 `learning-path` 的目标是：

- 告诉你这个项目该怎么读

那么这套 `learning-workbook` 的目标是：

- 告诉你每一阶段该读什么
- 告诉你每一阶段该动手做什么
- 告诉你怎么检查自己是不是真的看懂了

## 和 `learning-path` 的关系

- `learning-path` 更像“项目讲解版”
- `learning-workbook` 更像“学习任务版”

最好的方式是两套一起用：

1. 先在 `learning-workbook` 里看当前阶段的目标
2. 再去 `learning-path` 里读对应讲解
3. 然后回到 `learning-workbook` 做任务和自测

## 学习原则

- 不要求一次看懂全部
- 每个阶段只抓住当前最重要的流转关系
- 先能讲清楚“数据怎么流动”，再去追求代码细节
- 每一阶段至少做一个小改动，避免只读不练
