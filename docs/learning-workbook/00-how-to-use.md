# 0. 怎么使用这套教学版文档

## 你需要准备什么

- 能把后端跑起来
- 能把前端跑起来
- 知道怎么运行 `go test ./...`
- 知道怎么运行 `flutter test`

如果这些还不熟，先回去看：

- [learning-path/01-root-and-run.md](../learning-path/01-root-and-run.md)

## 每一阶段都怎么学

每一份阶段文档都有 5 个部分：

1. 学习目标
2. 必读文件
3. 阅读任务
4. 动手任务
5. 自测问题

## 你要避免的学习方式

不要这样学：

- 一口气把所有文件都点开
- 只看 UI，不看接口
- 只看 handler，不看 service
- 只会跑项目，不知道数据怎么流动

## 推荐节奏

每次只学一个阶段。

每学完一个阶段，至少做下面三件事：

1. 自己复述这一阶段的主流程
2. 自己画一个简单流程图
3. 自己做一个最小改动

## 建议记录模板

你可以每学完一阶段，写三行：

- 我今天看了哪些文件
- 我现在能讲清楚哪条流程
- 我下一步最想验证什么
